# 🎬 CineVerse — Interactive 3D Cinema Experience & Ticket Booking Platform

An ultra-modern, interactive 3D cinema ticket-booking platform built with **React**, **Three.js**, **React Three Fiber**, **GSAP**, **Zustand**, and **Tailwind CSS**.

---

## 🌟 Key Features

- **3D Auditorium & Real-Time First-Person Seat View**:
  - Click any seat to enter an authentic first-person eye-level perspective inside the cinema hall.
  - Realistic curved movie screen playing video trailers with procedural ambient stage glow.
  - 360° orbital camera exploration of the auditorium, seating tiers, and architectural details.

- **Dynamic Formats (2D · 3D · IMAX)**:
  - Instant toggle between **2D Cinemascope 4K**, **RealD 3D**, and massive floor-to-ceiling **IMAX with Laser**.
  - Dynamic 3D screen geometry and curvature that physically resize based on format.
  - Dynamic tier pricing automatically adjusting by format.

- **Dolby Atmos Surround Audio**:
  - High-definition trailer soundtrack with Web Audio API spatial audio panning according to seat position and deep cinematic subwoofer bass boost.
  - Wall-mounted surround speakers with dedicated illumination spotlights.

- **Event Discovery Hub & Hero Carousel**:
  - Multi-movie interactive hero slider featuring blockbusters (*Ramayana*, *Dune: Part Two*, *Avatar: Fire and Ash*, *Interstellar*).
  - Event categories for Movies, Live Concerts, Stadium Sports Screenings, and Midnight Premieres.
  - Fast filter and sort options (Price: Low to High / High to Low, Ratings, Featured).

- **Architectural Polish & Responsive Mobile UI**:
  - Elevated screen mounted flush to the proscenium stage wall.
  - Emergency Exit Door with illuminated green exit sign.
  - "View & Select" preview mode: inspect seat views freely before committing to billing.
  - Responsive mobile drawer switcher with Split, 3D, and Seats views.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
